# Thư mục ảnh minh họa

Đặt ảnh chụp màn hình vào đúng thư mục bên dưới. Nên dùng PNG, che số điện thoại, tên khách hàng, token, Job ID hoặc dữ liệu nhạy cảm trước khi đưa lên tài liệu.

## Danh sách ảnh cần chụp

| Thư mục | Ảnh cần thêm |
| --- | --- |
| `01-ket-noi-oa` | Màn hình thêm kết nối OA và trạng thái Đã kết nối |
| `02-tao-mau-tin` | Form tạo mẫu, logo sáng/tối, preview sáng/tối, trạng thái duyệt và Template ID |
| `03-cta` | Khu vực nhập CTA, URL và loại CTA |
| `04-tao-chien-dich` | Chọn mẫu, nhập tham số, chọn nguồn khách hàng và xác nhận gửi |
| `05-hang-doi-retry` | Hàng đợi, giờ cấm gửi, trạng thái queue và nút Retry |
| `06-credit-bao-cao` | Số dư Credit, lịch sử Credit và báo cáo gửi |
| `07-xu-ly-loi` | Chi tiết queue lỗi, lỗi CTA, lỗi logo và kết quả import Excel |
