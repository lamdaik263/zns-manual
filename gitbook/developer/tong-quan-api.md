# Tổng quan API

Khu vực API sẽ được bổ sung theo tài liệu kỹ thuật chính thức của nhà cung cấp dịch vụ.

## Dự kiến nội dung

- Thông tin xác thực.
- Cấu trúc request và response.
- Gửi tin ZNS bằng API.
- Truy vấn trạng thái tin.
- Webhook / callback.
- Mã lỗi và cơ chế retry.

> Không đưa token thật, thông tin khách hàng hoặc dữ liệu nhạy cảm vào ví dụ API công khai.
